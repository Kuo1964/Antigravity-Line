完整驗證說明指南 (Walkthrough)

🧪 實機驗證成果與功能總覽

全套系統已通過多次實機測試驗證，順利完成以下重點運作邏輯：

  • macOS 鎖定自動喚醒解鎖：caffeinate 點亮螢幕 + mac_unlocker 輸入密碼自動解鎖。
  • 網路祝賀圖片抓取：Bing Image Search 線上爬取帶有『早安 一切順心』中文文字的精美長輩圖。
  • LINE 桌面版精確發送：CoreGraphics 點擊 + 鍵盤 Return 雙重保險，發送至指定目標。
  • 螢幕狀態記憶與睡眠自動復原：若執行前為睡眠/鎖定，發送完畢後自動執行 pmset displaysleepnow 恢復睡眠鎖定！

🚀 實機鎖定測試步驟 (Private 測試)

  1. 執行測試命令：PYTHONPATH=. ./venv/bin/python scripts/test_private_lock_send.py --target Private --countdown 10
  2. 按下 Ctrl + Cmd + Q 鎖定 Mac。
  3. 觀察系統自動喚醒、解鎖、下載圖片發送給 Private，並在發送完成後自動熄滅螢幕睡回！

📅 每日雙時區自動化部署

一鍵安裝命令：bash scripts/setup_daily_schedule.sh

  • LaunchAgent 重開機自動啟動：com.antigravity.linebridge.plist 註冊為 macOS 背景守護進程，每次重開機自動載入！
  • 自動動態預約喚醒：每次任務執行完畢後，系統自動預約下一個時間點 (08:58 或 21:28) 的硬體喚醒！
