V13 硬體喚醒接力機制部署完成報告

為了突破蘋果作業系統「一天只能設定一次規律喚醒」的硬體限制，我已經為您部署了這套完美的「Root 喚醒接力」 (Wake Relay) 系統！

🎯 這次完成了什麼？

1. 新增喚醒接力工具 (`schedule_next_wake.sh`)

我撰寫了一支專門用來計算時間的小工具。它的任務很簡單：

只要給它一個目標時間（例如 `21:28:00`），它就會自動判斷「現在過了這個時間沒？」，然後精準地將下一次硬體喚醒時間排入系統底層。

2. 徹底升級一鍵設定腳本 (`setup_daily_schedule.sh`)

我將原本會被蘋果忽略一半的 `pmset repeat` 給移除了，取而代之的是，一鍵腳本現在會自動將接力任務寫入系統最高權限的 Root Crontab 中。

  • 每天早上 09:05：Root 系統自動發動，將硬體喚醒時間設為今晚的 `21:28:00`。
  • 每天晚上 21:35：Root 系統再次發動，將硬體喚醒時間設為明早的 `08:58:00`。

因為是 Root 權限，完全不需要您手動輸入密碼，電腦就像自動接力賽一樣，完美跨越了蘋果的限制！
