🚀 部署與啟動步驟指引

1. 設定環境變數

將 `.env.example` 複製為 `.env` 並編輯：


cp .env.example .env

填入您的 `LINE_CHANNEL_SECRET`, `LINE_CHANNEL_ACCESS_TOKEN`, `ALLOWED_USER_IDS` 與 `GEMINI_API_KEY`。

2. 安裝套件並啟動


pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

3. ngrok 本地 Webhook 轉接


ngrok http 8000

將 ngrok 產生的 HTTPS 網址（如 `https://xxxx.ngrok-free.app/webhook`）貼至 Line Developers Console 的 Webhook URL 欄位並啟用。
