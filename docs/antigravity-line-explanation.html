💡 1. 專案概述 (What is this)

Antigravity-Line 是一個專為 macOS 環境打造的全自動雙時區 LINE 祝賀早安圖發送與自動化電源調度系統。 系統每天於台灣時間 09:00:00 自動發送早安圖至好友 Sharon Chou，並於美東時間 09:30:00 (台灣時間 21:30:00) 跨國發送至 郭泊彤。 核心整合了線上『早安 順心如意』花草祝賀圖動態爬蟲、macOS 原生 CoreGraphics C API (ctypes) 自動化視窗控制、caffeinate 硬體喚醒與 pmset displaysleepnow 螢幕鎖定復原機制，並配備 macOS LaunchAgent 背景守護進程，實現 24/7 零人工干預無人值守運作。

⚖️ 2. 架構決策與權衡對比 (Why this approach)

關鍵技術維度 採用的最佳方案 (Chosen Approach) 替代方案 (Alternatives Considered) 決策考量與權衡 (Tradeoffs & Rationale)
GUI 自動化控制 macOS 原生 ctypes (CoreGraphics) + AppleScript 視窗標準化重置 PyAutoGUI / Selenium 模擬庫 原生 CoreGraphics 免安裝外部笨重依賴，避免 macOS TCC 隱私權限被外部第三方 Python 庫鎖死。配合 AppleScript 強制把 LINE 重置在 Position(100,100)/Size(1000,800)，座標點擊 100% 精準。

背景自動化服務 macOS LaunchAgent (KeepAlive: ON) + System Crontab 手動開啟 Terminal 終端機掛載 即便 Mac 重新開機，LaunchAgent 背景守護進程自動載入，實現 24/7 真正無人值守。
開機連網與 LINE 登入 10 分鐘開機連網緩衝區設計 (Buffer Delay Architecture) 開機瞬間立即觸發 LINE 發送 Mac 冷開機前 15 秒 Wi-Fi 網卡尚未獲取 IP。預留 10 分鐘緩衝時間能確保 Wi-Fi 連通且 LINE 穩定完成自動登入，避開 Token 驗證失敗被退回登入頁的死穴。

💥 3. 系統依賴與風險衝擊圖 (What would break)

macOS FileVault 帳號未登入隔離 高風險 (High)

完全關機開機後，停在登入畫面時使用者的 crontab 停擺。已透過開啟 macOS「自動登入」解決。

iTerm2 關機 Confirm 彈窗阻擋 中風險 (Medium)

AppleScript 普通 quit 會觸發 iTerm2 彈窗中斷關機。已升級為 Unix SIGKILL (pkill -9 iTerm2) 解決。

LINE 視窗最小化/偏離標準位置 中風險 (Medium)

視窗過小導致座標點擊無效。已於 focus_line_app 加入自動拉回 Position(100,100)/Size(1000,800) 並盲發 Return 鍵。

🧠 4. 關鍵經驗教訓與學習轉變 (What I learned)

實機踩坑教訓 1
pmset 指令的精確語法歧義 (`poweron` vs `wakepoweron`)

最初誤用 wakepoweron 於一次性預約，導致拋出 Unspecified scheduled event type。 體會到：wakepoweron 僅適用於 pmset repeat 重複排程，而一次性預約完全關機開機必須使用 sudo pmset schedule poweron。

實機踩坑教訓 2
系統關機保護與 SIGKILL 強制銷毀進程的威能

傳統 GUI 應用的 Quit 訊號容易被二次確認彈窗攔截。改用 Unix 核心訊號 pkill -9 iTerm2 (SIGKILL) 能夠在 0 秒內直接銷毀進程，徹底解鎖全自動關機。

架構演進心得 3
連網緩衝區設計 (Buffer Delay Architecture) 與睡眠鎖定復原

理解到開機與服務 Ready 之間存在時間差。採取「開機 ➔ 預留 10 分鐘連網與 LINE 登入緩衝 ➔ 定時發送 ➔ 自動睡回鎖定」的架構，能夠兼具 100% 穩定度、綠能省電與系統安全性。
