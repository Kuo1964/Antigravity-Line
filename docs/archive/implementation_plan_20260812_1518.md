# V14.1 LINE 視窗喚醒修復與驗證計畫 (獨立測試分支)

非常同意您的做法！在不動到目前主程式的前提下，我們先開一個「測試分支 (測試腳本)」來驗證我的解法是否能 100% 把消失的 LINE 視窗給叫出來。

## 🔍 問題核心與解法思路

**目前的問題**：
在原本的 `focus_line_app()` 裡，我們用了 `tell application "LINE" to activate`。這個指令只能把 LINE 從背景拉到前景，但**如果主視窗被您點了紅色叉叉關閉，`activate` 是不會主動把視窗生出來的**，所以接下來找 `window 1` 就會報錯。

**解決思路**：
在 LINE 桌面版中，按下快捷鍵 `Command + 1` (或是 `Command + 2`)，系統會強制彈出主聊天室視窗。
我們要在 AppleScript 聚焦 LINE 之後，強制追加送出一個 `Command + 1` 的鍵盤指令，確保主視窗必定存在！

## 🛠️ 驗證計畫 (如何進行測試)

為了不碰到主程式，我將建立一支完全獨立的測試腳本：`temp_test/test_line_reopen.py`。

### 測試步驟：
1. **建立測試腳本**：腳本內會包含改良版的 `focus_line_app_test()` 與 `get_line_window_bounds_test()`。
2. **手動製造故障情境**：在測試開始前，我會請您**開啟 LINE，然後點擊左上角的紅色叉叉把主視窗關掉** (讓 LINE 只在右上角選單列活著，模擬昨晚的情境)。
3. **執行測試腳本**：
   - 腳本會先嘗試聚焦 LINE，並發送 `Command + 1`。
   - 腳本接著會嘗試抓取 `window 1` 的座標。
   - 如果腳本能在終端機印出 `成功獲取 LINE 視窗座標: x=..., y=...`，並且您親眼看到 LINE 視窗彈了出來，就代表這個解法完美成功！
