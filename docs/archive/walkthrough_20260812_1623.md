## 🚀 重構亮點：MacOSUIAdapter
**[新增] `app/services/macos_ui_adapter.py`**
我們創造了這個乾淨俐落的轉接器 (Adapter)，將所有的「髒活」封裝起來：
1. **CoreGraphics ctypes**：`native_click()`
2. **AppleScript 原生命令**：`execute_applescript()`, `reopen_app()`, `unhide_window()`
3. **Appscript 系統事件**：`get_window_bounds()` (包含 Retry 機制), `send_keystroke()`, `send_keycode()`

**[改寫] `app/services/line_desktop_controller.py`**
現在這個控制器的原始碼從 194 行精簡到 80 行以內！它已經被徹底淨化，變成了一份「純粹的商業流程圖」：
```python
# 商業流程現在變得像講話一樣清晰，完全沒有 AppleScript 或 ctypes 雜訊
adapter = MacOSUIAdapter()
adapter.reopen_app("LINE")
bounds = adapter.get_window_bounds("LINE")
adapter.native_click(search_x, search_y)
adapter.send_keystroke("a", using_cmd=True)
adapter.send_keystroke(target_name)
...
```

## 🎯 產生的價值
- **Locality (局部性) 極高**：未來 macOS 升級如果導致點擊失效，我們只要去修 `macos_ui_adapter.py` 就好，LINE 控制器連碰都不用碰。
- **擴充 Leverage (槓桿效應)**：這套 Adapter 可以直接拿來給其他專案（例如 WhatsApp 或 Telegram 的自動化）重複使用。
