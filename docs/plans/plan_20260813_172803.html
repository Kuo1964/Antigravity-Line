LINE Webhook Verify 404 雙防線與 Root Path 容錯修復計畫 (Implementation Plan)

🔍 診斷原因 (Root Cause Analysis)

根據您提供的 LINE Developers 後台「Verify」驗證失敗截圖 (`404 Not Found`) 進行深度診斷：

1. LINE 平台 Verify 驗證機制與 404 阻斷：

  • 當在 LINE Developers 後台點擊「Verify」或發送訊息時，LINE 官方伺服器會嘗試發送 HTTP POST 進行健康與連線驗證。
  • 若後台 Webhook URL 未加上 `/webhook` 後綴（填寫成 `https://professed-equivocal-lagoon.ngrok-free.dev`），請求落入根目錄 `POST /` 時，FastAPI 會直接回傳 `404 Not Found`！
  • 一旦 LINE 平台驗證得到 404，LINE 官方會硬性封鎖並停用所有手機對話訊息的轉發！

2. 背景 Uvicorn 常駐連線脫鉤：

  • Shell 進程退出時若未建立完全獨立之守護進程，會導致 FastAPI 在重啟瞬間連線中斷。
