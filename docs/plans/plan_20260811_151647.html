Line Bot 控制 Antigravity 雙向溝通管道工具導入計畫

設計並實作一個透過 Line Messaging API 與 Google Antigravity SDK 整合的雙向控制服務。使用者可透過 Line 訊息對 Antigravity Agent 下達指令，系統透過異步推播模式即時回覆與處理任務結果。

🔑 核心功能模組

1. FastAPI Webhook 服務與驗證

  • 驗證 Line 簽章 (`X-Line-Signature`)，確保請求安全性。
  • Line User ID 白名單過濾機制 (`ALLOWED_USER_IDS`)。

2. Line 訊息解析與控制指令處理

  • 文字指令解析：處理一般對話或專屬控制指令 (如 `/reset`, `/clear`, `/status`, `/help`)。
  • 異步推播模式：接收 Webhook 後秒回 `200 OK`，背景任務觸發 Agent 執行。

3. Google Antigravity SDK Agent 整合與 Session 管理

  • 為每個授權使用者開闢與維護連續的 Agent Conversation Session。
  • 整合 `google-antigravity` 套件，處理 Agent 的推論與工具執行。
  • 任務完成後將結果透過 Line Messaging API 的 `push_message` 發送給使用者。

4. 部署與容器化

  • 提供 `docker-compose.yml` 及 `.env.example`。
  • 提供 `ngrok` 本地測試說明文件。

🧪 Verification Plan

自動化/單元測試 (Automated Verification)

  • 撰寫 `tests/test_webhook.py` 驗證白名單過濾與特例指令 (`/reset`, `/status`) 解析。

手動與即時測試 (Manual Verification)

1. 啟動 FastAPI Webhook 服務（`uvicorn app.main:app --reload` 或 `docker-compose up`）。

2. 使用 ngrok 開啟 Local 轉接：`ngrok http 8000`。

3. 將 ngrok 產生的 HTTPS 網址貼至 Line Developers Console Webhook URL。

4. 使用獲授權的 Line 帳號發送對話與指令測試（如「你好，請幫我分析 Antigravity 專案」或「/reset」）。

5. 驗證非授權帳號發送訊息時是否被封鎖與拒絕。
