🔍 探查根因 (Root Cause Analysis)

透過 `ps aux` 進程快照與 `execution_trace.log` 對照，100% 徹底揭露連問 3 次均無回應的真正死穴：

1. FastAPI (Uvicorn) 伺服器進程在背景默默死亡：

  • 經 `ps aux | grep uvicorn` 檢查，本機 `uvicorn app.main:app` (Port 8000) 伺服器完全處於終止停止狀態 (Process Not Found)！
  • 原因為 `start.sh` 在 Shell 腳本完成後，背景子進程未綁定 `nohup` / `disown` 正統守護進程，致使 Task 結束時遭 OS 自動回收終止。

2. ngrok 轉發失敗 (Connection Refused)：

  • 當您在 16:58、16:59、17:09 於手機 LINE App 發送訊息時，ngrok 收到 HTTP POST 欲轉轉送給 `127.0.0.1:8000`，但因本機 Uvicorn 已死亡，導致連線連拒 (502 Connection Refused)，系統連一字封包都沒接到。
