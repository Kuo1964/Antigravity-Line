🔍 Bug Diagnosis (為何圖片沒貼上 LINE 視窗？)

您提供的截圖與檔案資訊非常精準，直接推翻了前面的「假圖片」假說。這張早安圖片是100% 完美的 JPEG 圖檔，而且日誌顯示它也確實成功被塞進了 Mac 的剪貼簿中！

既然剪貼簿裡有圖，那為什麼 `Cmd+V` 沒有把它貼上？

我仔細比對了腳本滑鼠點擊的座標與 LINE 介面的相對位置，抓到了這個真正的元凶：「手殘點錯位置，導致輸入框失去焦點！」

事發還原：

1. 腳本成功點擊了左側的「Sharon Chou」搜尋結果，此時右側聊天室開啟，LINE 其實已經自動把游標對準了底下的輸入框。

2. 但是！我們的腳本為了「保險起見」，安排了一個強制點擊輸入框的動作（步驟 D）。

3. 腳本計算的點擊座標是 `視窗最底部往上 60 像素 (win_h - 60)`。

4. 問題來了：macOS 的視窗外框通常包含了一圈透明的陰影（Shadow），這會被算進視窗總高度裡。扣掉陰影後，`往上 60 像素` 這個位置，剛剛好落在 LINE 輸入框下方的「工具列」（也就是有迴紋針、書籤、笑臉圖案的那一排）！

5. 於是，腳本「自作聰明」地點擊了工具列上的空白處。這致命的一擊，直接把原本在輸入框裡的打字游標給點掉了（失去焦點）。

6. 接下來腳本如常送出 `Cmd+V` (貼上) 與 `Return` (發送)，但因為游標已經不在輸入框裡，這些快捷鍵全部打在了空氣中，LINE 完全沒有反應。
