完整設計計畫 (Implementation Plan)

📌 雙時區 LINE 早安圖定時自動發送與 Mac 睡眠狀態自動復原系統

本計畫滿足用戶的核心需求：

  • 任務一：台灣時間 (UTC+8) 每日 09:00 發送早安圖片給 LINE 好友 Sharon Chou。
  • 任務二：美東時間 (UTC-4) 每日 09:30（對應台灣時間每日 21:30）發送早安圖片給 LINE 好友 郭泊彤。
  • 無縫睡眠與鎖定處理：無論 Mac 處於深度睡眠、休眠或螢幕鎖定狀態，均能自動喚醒與恢復狀態。
  • HTML 開發歷程報告：產出視覺化報告，並於後續每次更新時自動修改維護。

📅 定時任務與喚醒時程表

任務標的 目標好友 對應台灣時間 macOS 硬體自動喚醒時間 執行後動作
任務一 Sharon Chou 每日 09:00:00 每日 08:58:00 100% 恢復執行前原始狀態 (自動睡回/鎖定)
任務二 郭泊彤 每日 21:30:00 每日 21:28:00 100% 恢復執行前原始狀態 (自動睡回/鎖定)

🔄 全自動發送與狀態復原流程

  1. macOS RTC 喚醒：每日 08:58 與 21:28 由硬體晶片自動點亮 Mac 螢幕。
  2. 狀態記憶：detect_mac_screen_state() 紀錄發送前的鎖定/睡眠狀態。
  3. 喚醒與解鎖：mac_unlocker 進行 caffeinate 喚醒與密碼解鎖（若未鎖定則跳過密碼）。
  4. 網路圖片抓取：Bing Image 搜尋爬取『早安 一切順心』當日最新長輩祝賀圖。
  5. LINE 桌面版發送：CoreGraphics 原生點擊 + 鍵盤 Return 雙重保險，發送圖片至指定對話框。
  6. 自動睡回鎖定：restore_mac_screen_state() 呼叫 pmset displaysleepnow 自動將 Mac 恢復至原先的睡眠鎖定狀態！
